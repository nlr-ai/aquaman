# WPdx Lagos normalized snapshot

Source: Water Point Data Exchange (NGA), published by Water Point Data Exchange through HDX: https://data.humdata.org/dataset/wpdx_nga

HDX declares **Creative Commons Attribution Share-Alike**. Its metadata does not declare a version or licence URL. That designation applies to the source-derived data here; the application source code remains separately UNLICENSED. Preserve source attribution and this licence designation when reusing the data.

Aquaman selected Nigeria / Lagos records, mapped fields, assigned stable type-prefixed two-word app nicknames while preserving source identifiers and stable internal identifiers, and set current availability/access/price/quality to unknown. Original source organisations and dataset titles accompany each point. Raw historical condition and water-presence fields are preserved without resolving contradictions. Predictions and subjective quality are not treated as verified evidence.

There are 1,829 records with survey dates from 2010-01-01 to 2019-11-02. Neither source-file update time nor import time is a fresh field observation. Current water availability, potability and coordinates have not been locally verified. See index.json for the download URL, retrieval timestamp, source update timestamp and SHA-256 of the original CSV.
